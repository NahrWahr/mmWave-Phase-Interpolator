# Weekly Presentation Archive

Each entry is a self-contained snapshot directory: `YYYY-MM-DD-slug/` with that
week's `main.tex` and `main.pdf`. Reusable TikZ snippets / PGF figures live in
the top-level `figures/` (committed on the `presentation` branch) so they can
be `\input` from any week's deck.

**Convention** — the live `main.tex` at the branch root is *this week's* deck.
At the end of each week, copy it into a new dated archive directory and tag
the commit `pres/YYYY-MM-DD`.
